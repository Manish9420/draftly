## 5. AI Tools Used

The following AI tools were used during development:

- **ChatGPT — Free account:** Assisted with implementation guidance, debugging, database connectivity troubleshooting, and documentation.
- **Claude — Free account:** Used as an AI-assisted development resource.

AI assistance supported the development process. The application was tested manually, including verification of document creation and persistence in the deployed environment.

## 6. Current Limitations

- Authentication is not fully integrated with document ownership and access control.
- Secure document sharing and collaborator permissions are incomplete.
- Real-time collaborative editing is not implemented.

These limitations are disclosed to accurately represent the current state of the application.
